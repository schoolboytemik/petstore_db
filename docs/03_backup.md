# Резервное копирование базы данных

Резервное копирование базы данных выполняется автоматически с помощью  
автозапуска `.bat`-файла через **Планировщик задач Windows**.

Запуск выполняется **ежедневно в 21:00** (или в другое время после закрытия магазина).

Такой подход позволяет регулярно создавать резервные копии базы данных и обеспечивает возможность восстановления данных в случае сбоев системы.

---

## Пример содержимого `.bat` файла

```bat
@echo off
set PGPASSWORD=admin123

pg_dump -U postgres -F c -b -v ^
-f "C:\Backups\db_backup_%date:~-10,2%%date:~-7,2%%date:~-4,4%.backup" ^
petshop_db
